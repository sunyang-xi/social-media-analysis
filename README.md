# 社交媒体平台用户行为分析

## 项目简介
基于社交媒体平台（YouTube、Twitter、Reddit）的用户行为数据，使用 Python 进行数据清洗、多维度分析和可视化，探索各平台的用户分布、活跃规律、话题偏好、内容健康度及互动表现。

## 分析工具
- Python 3.12
- pandas（数据处理）
- matplotlib / seaborn（可视化）

## 分析维度
1. 平台用户分布
2. 用户活跃时间（一周内）
3. 平台话题偏好
4. 情感与毒性分析
5. 互动表现

## 核心结论
- 三大平台用户分布均衡，差异在 2% 以内
- Reddit 周五最活跃，YouTube 集中在周一/周四，Twitter 较为平稳
- YouTube 用户关注 Finance/Technology，Twitter 关注 Sports，Reddit 话题分布多元
- YouTube 正面、低毒性内容占比最高，内容环境相对健康
- YouTube 高频互动占比最高（45%），用户参与度领先
